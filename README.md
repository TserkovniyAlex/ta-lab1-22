# Lab1-Sorting

Лабораторна робота №1 з дисципліни «Теорія алгоритмів» — квадратичні алгоритми сортування.

- **Виконав:** Церковний О. Г., група АІ-254
- **Варіант:** 22
- **Вхідна послідовність:** `19, 75, 43, 31, 5, 66, 62, 34, 76`

## Опис

У роботі реалізовано та протестовано алгоритми сортування зі складністю O(n²):

- сортування вибором (`selection_sort.py`);
- сортування вставками (`insertion_sort.py`).

Для кожного алгоритму підраховується кількість порівнянь та присвоювань.


| Алгоритм | Порівняння | Присвоювання | Разом |
|---|---|---|---|
| Selection Sort | 44 | 36 | 80 |
| Insertion Sort | 21 | 52 | 73 |

Відсортована послідовність: `5, 19, 31, 34, 43, 62, 66, 75, 76`

## Запуск

```
python selection_sort.py
python insertion_sort.py
```
